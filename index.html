        How it works

        1. Press Open in TCGplayer on a batch. TCGplayer's Mass Entry page opens in a new tab with those cards already filled in.
        2. In the Item Options popup, keep the printings and conditions you want, then press Add to Cart. TCGplayer picks the cheapest sellers for you.
        3. Come back here and open the next batch. Every batch goes into the same cart. Opened batches get a checkmark, so you can stop and pick up later on the same device.

        If something goes wrong

        • Some lines turn red ("could not be found" or "not enough quantity"): listings change all the time. Delete the red lines on the TCGplayer page and press Add to Cart again.
        • "Your cart is full": TCGplayer caps cart size. Check out (or save for later) what you have, then carry on with the next unchecked batch.
        • The popup shows no printings, or no game is selected: press Edit Items, pick Riftbound: League of Legends Trading Card Game under Select Product Line, then Add to Cart. If it happens every time, see Advanced below.
        • Rares and up are foil-only in Riftbound. If you untick Foil in Item Options, those cards will fail.
        • On Android, if the TCGplayer app opens instead of the website and nothing is filled in, long-press the button and choose Open in new tab.

        Prices here are TCGplayer market prices from the last data refresh. Your real total depends on which sellers TCGplayer picks, plus shipping.

        Advanced

        Sent as productline= so Mass Entry selects Riftbound for you. Change it only if TCGplayer stops picking Riftbound automatically.

        Product IDs pin down the exact printing. Switch to names and set codes if TCGplayer ever rejects the ID lines. Card names are unique within each set, so both pick the same card.

        Add a deck

        Paste a deck code or a deck list from any Riftbound deck site (see Find decks below). Lists can look like 3 Void Seeker, 3x Void Seeker (OGN-024) or OGN-024 x3, with or without headings like Runes: and Sideboard:.

          Find decks

          Fan sites with Riftbound decks. Open a deck there, use its Copy deck code or Export button, and paste the result above. These sites aren't connected to this app. Play-rate and win-rate stats stay on their pages: Riot's developer policy doesn't let fan apps publish them.
